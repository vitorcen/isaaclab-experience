3. USD 材质修复 — Why your G1 renders white, and the real fix

根因 · Root cause: MimicKit 的 g1.usd 在转换过程中把 MJCF 的 per-geom rgba 压成了**单一 DefaultMaterial=(1,1,1) 白**。改 visual_material 或 PBR 调色都治标。
正解 · Fix: 从 g1.xml 反推 per-mesh rgba，新建对应 UsdPreviewSurface 材质，重绑 36 mesh。

关键代码 — Core fix

# scripts/g1_usd_recolor.py 核心 — parse MJCF and rebind USD meshes

def parse_mjcf_colors():
    """ Visual  in g1.xml: contype=0 conaffinity=0 group=1, with rgba per mesh """
    colors = {}
    for geom in ET.parse(MJCF).getroot().iter("geom"):
        mesh = geom.attrib.get("mesh")
        if not mesh or geom.attrib.get("contype") != "0":
            continue
        rgba = geom.attrib["rgba"].split()
        colors[mesh] = tuple(float(p) for p in rgba[:3])
    return colors  # {mesh_name: (r, g, b)}

# build one UsdPreviewSurface Material per unique color, then per-prim rebind:
for prim in stage.TraverseAll():
    if prim.GetTypeName() != "Mesh":
        continue
    color = mjcf_colors.get(prim.GetName())
    if color:
        UsdShade.MaterialBindingAPI.Apply(prim).Bind(
            UsdShade.Material(stage.GetPrimAtPath(color2matpath[color])))
